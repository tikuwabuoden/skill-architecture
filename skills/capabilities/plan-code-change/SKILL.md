# Plan Code Change

このCapabilityはWorkflowが内部Skillとして読み込んで使う。CodexのSkill探索対象へインストールせず、ユーザーの依頼から直接起動しない。

要求とコードベースの事実を、実装時に新しい設計判断が残らない変更計画へ変換する。ファイルは変更しない。

## Planning

1. 実現する振る舞い、対象外、互換性などの制約を確認する。
2. 影響範囲調査の結果を利用し、計画を左右する不足だけを追加調査する。
3. 既存パターンに沿う最小の方針を選び、主要な代替案がある場合は選定理由を示す。
4. 変更する責務、処理の流れ、外部から見える契約、失敗時の挙動を決める。
5. 変更した振る舞いに対応する検証方法を決める。

ユーザーの意図を変える判断が必要なら計画を確定せず確認する。実装者が決められる局所的な詳細まで固定しない。

## Result

- 実現する振る舞いと対象外
- 採用する実装方針
- 変更する責務と処理の流れ
- インターフェースまたはデータへの影響
- 影響評価で判明した制約への対応
- テストと検証方法
- 未確定事項とリスク
