# Verify Code Change

このCapabilityはWorkflowが内部Skillとして読み込んで使う。CodexのSkill探索対象へインストールせず、ユーザーの依頼から直接起動しない。

要求、変更差分、リポジトリで利用可能な検証手段を照合し、変更が確認できたかを判断する。検証中にコードは修正しない。

## Verification

1. 実現する振る舞い、変更差分、影響範囲を確認する。
2. 変更した振る舞いを直接確認できるテストを優先し、影響に応じて静的検査、ビルド、広い回帰テストを選ぶ。
3. 選んだ検証を実行し、コマンド、成功、失敗、実行不能を区別して記録する。
4. 差分を確認し、要求外の変更、テスト漏れ、互換性への影響がないかを確認する。

失敗した検証を成功扱いにしない。環境上実行できない検証と、失敗した検証を区別する。修正が必要な場合は、問題と根拠を呼び出し元へ返す。

## Result

- 検証した要求
- 実行したチェックと結果
- 差分確認の結果
- 失敗または実行不能だった検証
- 残存リスク
- 判定: `verified` または `not-verified`
