# Assess Change Impact

要求された変更とコードベースの現状から、変更によって影響を受ける可能性のある範囲を根拠付きで示す。ファイルは変更しない。

## Assessment

1. 変更対象に関連する呼び出し元、依存先、共有データ、不変条件を追跡する。
2. 公開インターフェース、保存データ、設定、権限、運用への影響を、変更に関係する範囲で確認する。
3. 更新または追加が必要になり得るテストと文書を特定する。
4. 確認できた影響と可能性だけの影響を区別し、根拠のない範囲を確定事項にしない。

## Result

- 影響を受ける呼び出し元と依存先
- インターフェース、データ、設定への影響
- 互換性または移行上の懸念
- 必要になり得るテスト、文書、運用対応
- 影響ごとの根拠
- 未確認箇所とリスク
